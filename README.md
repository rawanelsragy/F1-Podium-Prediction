# F1-Podium-Prediction

Formula 1 podium prediction project using historical race data, data engineering, machine learning, and explainable AI.

## Objective
Predict whether each driver will finish on the podium using only information available after qualifying and before the race starts.

## Dataset
Formula 1 World Championship (1950–2024), Kaggle / Ergast dataset.

## Target
- `1` = Podium finish (`positionOrder <= 3`)
- `0` = Non-podium finish

## Main Tasks
- Exploratory Data Analysis
- Data Cleaning
- Data Engineering Questions
- Feature Selection and Engineering
- Machine Learning Models
- Neural Network
- Model Evaluation
- Feature Ablation
- Explainable AI
